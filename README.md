# System Alert — Developer Status HUD

An interactive, cyberpunk-inspired developer dashboard that presents programming progress through an RPG-style status screen. The interface combines a terminal-style boot sequence, quest selection, and level-gated modal interactions.

## Project links

- **[Open the live demo](https://lixnqkfpxev10hvok8us.codedex.me)**
- **[View the Codédex project](https://www.codedex.io/@OVIEE/build/system-alert-solo-developer-status-hud)**

## Features

- **Terminal-style boot sequence** — animated text introduces the status screen.
- **Interactive quest selection** — selecting a quest updates its active state.
- **Level-gated dialogs** — locked quest tracks use modal alerts.
- **Distinct visual direction** — dark purple colors, high contrast, and retro pixel typography.
- **Responsive layout** — designed to present the HUD across different screen sizes.
