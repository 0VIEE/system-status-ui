# ⚡ System Alert: Solo Developer Status HUD

An interactive, cyberpunk RPG status screen inspired by *Solo Leveling* system interfaces. Built with responsive layout structure, custom terminal text animations, and dynamic modal alerts.

## 🚀 Links
* **Live Demo:** [System Alert Status HUD](https://lixnqkfpxev10hvok8us.codedex.me)
* **Codédex Build Project:** [@OVIEE on Codédex](https://www.codedex.io/@OVIEE/build/system-alert-solo-developer-status-hud)

## ✨ Features
* **Retro Terminal Booting Animation:** Custom typing sequence rendering stats on launch.
* **Interactive Quest Selection:** Dynamic active state highlighting for developer milestones.
* **Level-Gated Modals:** Custom JavaScript popups blocking locked quest tracks.
* **Solo Leveling Cyberpunk Aesthetic:** Dark purple high-contrast color scheme with custom retro pixel fonts.

## 🛠️ Stack & Hardware
* **Frontend:** HTML5, CSS3, JavaScript
* **Platform:** Codédex
* **Dev Rig:** AMD Ryzen 7 | NVIDIA RTX 4050 | 16GB RAM
